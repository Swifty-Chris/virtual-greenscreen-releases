# Virtual Greenscreen – Downloads

Offizielle Download-Seite für **Virtual Greenscreen**, die macOS-App von cs-training: Sie stellt dich vor der Kamera
frei, ganz ohne echten Greenscreen, und setzt dich in ein virtuelles Studio – deine Präsentation läuft auf der Leinwand
oder dem Fernseher im Raum. In Teams, Zoom oder Meet wählst du die App einfach als Kamera aus.

> **Quellcode:** privat.

---

## Download

**Voraussetzungen:** Mac mit Apple-Chip (M1 oder neuer), macOS 15 oder neuer.

1. Die neueste `.dmg` von der [**Releases**-Seite](https://github.com/Swifty-Chris/virtual-greenscreen-releases/releases/latest) laden.
2. Doppelklick auf die `.dmg` und **Virtual Greenscreen** auf den Ordner **Programme** ziehen. Bitte von dort starten –
   nur dann lässt sich die virtuelle Kamera einrichten.
3. Beim ersten Start den Kamerazugriff erlauben. Für Teams, Zoom oder Meet die Kameraerweiterung erlauben
   (Systemeinstellungen › Allgemein › Anmeldeobjekte & Erweiterungen › Kameraerweiterungen) und dort die Kamera
   „Virtual Greenscreen“ wählen.

Die App ist **mit Developer ID signiert und von Apple beglaubigt** – macOS installiert sie ohne Warnung.

**Updates:** Die App fragt einmal am Tag nach einer neuen Version (Sparkle). Von Hand: *Virtual Greenscreen › Nach Updates suchen …*

**Anleitung:** In der App unter *Hilfe › Anleitung: Studio einrichten* (kurzes Video).

---

`appcast.xml` in diesem Repository ist die Versionsliste für die Updates.
